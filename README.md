# Exalted Dynasty

Crusader Kings III mod. Version 0.3.0. Supported game version 1.20.*.

Canonical working copy: `Documents/Development/CK3 Mods/ed`.

House exaltation with mild member buffs, renown faucet, cohesion pulse, hub legacy track, secondary cadet blessing (cap 1–2), Succession Unity Dynasty Pact soft peer, and a mild house war banner.
